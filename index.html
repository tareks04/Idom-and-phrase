ব্যবহারবিধি

  1. Q&A list একসাথে Paste করুন। প্রতিটি প্রশ্ন Q270. দিয়ে এবং উত্তর Ans: দিয়ে শুরু করুন।
  2. MAT, DAT, DU, BCS বা Other Universities আলাদা লাইনে লিখলে category ধরা হবে। প্রশ্নে [MAT:24-25] ধরনের ট্যাগ থাকলেও রাখা হবে।
  3. Q&A বিশ্লেষণ করুন চাপলে Question Bank তৈরি হবে। Import Settings-এ Append বা Replace বেছে নিতে পারবেন।
  4. MCQ বানাতে অন্তত চারটি পৃথক Answer প্রয়োজন। একটি প্রশ্নের সঠিক উত্তরের বাইরে অন্য তিনটি আলাদা Answer distractor হবে।
  5. Question Bank-এ গিয়ে প্রশ্ন Edit/Delete করতে পারবেন। TXT/JSON Export দিয়ে Backup রাখুন।
  6. ডেটা এই Browser-এ Auto-save হয়। Browser data মুছে ফেললে ডেটা হারাতে পারে—তাই Backup Export রাখুন।
